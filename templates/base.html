Gemini MCP Setup Guide

Connect the VaultSwap Trade MCP & Assistant Skill to Gemini / Antigravity

Gemini Mobile App Setup (iOS & Android)
Cloud Run Hosted

Because phone operating systems cannot run local Python scripts, Google routes custom MCP tools through your Google Account sync. You configure it once on the web:

Your Cloud Run MCP Endpoint URL to Copy:
https://YOUR-APP-URL.run.app/mcp
* The button automatically grabs your current deployed origin and appends /mcp
Step-by-Step Instructions:
  1. Open gemini.google.com/devmode (or gemini.google.com > Menu > Settings > Connected Apps) in your browser.
  2. Make sure you are signed into the same personal Google account you use on your phone.
  3. Click + Create new / Add Custom App.
  4. Enter App Name: VaultSwap
  5. Paste the copied URL above into MCP Server URL.
  6. Click Save & Connect.
  7. Open the Gemini mobile app on your phone. Type @VaultSwap or ask: "What cards are up for trade in the pod?"
1 Desktop / Antigravity Setup (Local stdio)

Add the following block to your local config at ~/.gemini/config/mcp_config.json: 

{
  "mcpServers": {
    "vaultswap-trades": {
      "command": "C:\\Users\\jpmcl\\Python Development\\.venv\\Scripts\\python.exe",
      "args": ["C:\\Users\\jpmcl\\Python Development\\VaultSwap\\mcp_server.py"]
    }
  }
}
2 Workspace Skill (Automatic)

The vaultswap-trade-assistant skill is packaged inside .agents/skills/vaultswap-trade-assistant/SKILL.md. Gemini automatically activates it when you talk about MTG cards, trades, or Mighty Meeple.

3 Available MCP Tools
list_trade_cards Search/filter all public pod trade & meeple-bound listings
get_trade_card_metadata Card details, cross-printing copies in pod, & store buylist
list_pod_traders Active trader profiles, handles, and binder valuations
get_pod_trade_summary Pod trade metrics, top cards by value, & multi-copy extras
4 Sample Prompts to Try in Gemini
  • "What cards are currently up for trade in the pod?"
  • "Does anyone have a Rhystic Study or Cyclonic Rift for trade?"
  • "Show me all foil cards available for trade over $10."
  • "What cards are marked Meeple Bound and what is their buylist cash value?"
